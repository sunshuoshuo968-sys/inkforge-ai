# InkForge AI · 墨构

> **让灵感，长成一部作品。**

InkForge AI（墨构）是一套为长篇小说创作者设计的 AI 创作工作台。它不只是一个“生成文字”的聊天窗口，而是一条从灵感、设定、大纲到章节成稿的完整创作轨道：你决定故事要去哪里，墨构负责让它始终保持方向、记得上下文，并持续向前。

## 产品能力

### 从一个念头开始

输入一句创意，AI 可以协助展开：

- 作品定位、题材与一句话简介
- 角色卡、人物动机与关系冲突
- 世界观规则、地点、势力与历史
- 主线、支线、伏笔与章节钩子
- 分章目标、阻力、代价和章末悬念

### 让长篇始终连贯

墨构把创作资料集中在同一部作品中，帮助你持续管理：

- 章节大纲与正文编辑
- 角色资料库
- 世界观、情节和灵感笔记
- 章节记忆、时间线与伏笔
- 章节状态、目标字数和创作进度

### 每一章都经过质量流程

支持三种创作模式：

| 模式 | 适合场景 | 工作流 |
| --- | --- | --- |
| 快速初稿 | 快速铺开故事 | 大纲规划 → 分章写作 |
| 标准成稿 | 日常连载与稳定产出 | 写作 → 审读 → 系统修订 |
| 番茄发布版 | 发布前的完整检查 | 写作 → 审读 → 修订 → 发布终审 |

章节 AI 助手还支持两种协作方式：

- **智能对话**：讨论开篇、节奏、人物动机和修改建议，不直接改动正文。
- **接管本章**：生成一份可预览的候选修订稿，确认后替换正文，并保留原文备份，随时可以恢复。

## 设计体验

墨构采用沉浸式的创作界面：

- 产品级首页：从第一次打开就能理解产品价值与工作方式
- 编辑器式章节工作台：章节列表、正文纸张、状态栏和 AI 面板协同工作
- 支持浅色 / 深色主题
- 桌面端与移动端自适应
- 拖拽式章节 AI 面板，适合边读边改
- 本地优先保存，作品数据默认留在当前浏览器

## 本地运行

环境要求：

- Node.js 18+
- pnpm 10+

安装依赖并启动开发服务器：

```bash
pnpm install
pnpm dev
```

启动后打开终端显示的本地地址，默认通常为：

```text
http://127.0.0.1:5173
```

生产构建：

```bash
pnpm build
```

本地预览生产版本：

```bash
pnpm preview
```

## AI 模型配置

进入应用右下角的「设置」，选择模型提供商并填写：

- 接口地址
- API Key
- 模型名称

当前内置配置入口包括 DeepSeek、OpenAI 和 Kimi。API Key 只保存在当前浏览器的本地数据中，不会写入仓库文件。

## 数据与备份

墨构默认使用浏览器本地存储保存作品数据。你可以在「设置」中：

- 导出完整备份
- 导入已有备份
- 管理主题、编辑器字号与字体
- 管理模型提供商和接口配置

建议在更换浏览器或清理站点数据前先导出备份。

## 项目结构

```text
src/
├── App.tsx       # 应用界面、工作台与交互流程
├── ai.ts         # AI 请求与流式响应
├── data.ts       # 作品、章节与默认数据模型
├── storage.ts    # 本地保存、导入与导出
├── types.ts      # TypeScript 类型定义
├── workflows.ts  # 写作、审读、修订与终审提示词
└── styles.css    # 全局主题与响应式界面样式
```

## 项目定位

InkForge AI 适合需要长期维护世界观、持续连载章节，或希望把 AI 纳入稳定写作流程的创作者。

它的目标不是替你写完一个故事，而是让你更容易开始、更少遗忘、更快修订，并最终留下真正属于你的笔迹。
